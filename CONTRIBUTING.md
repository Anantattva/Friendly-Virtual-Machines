## 💥 Contributing Guidelines

If you are someone who is curious to showcase his/her own samples on this repository, consider the following standards:
- **Code Size:** Ensure the codebase is compact and fits within 10 files with 7,000 lines of code or less (or atmost 10,000 lines of code if it covers advanced topics like GC or JIT).
- **Zero Dependency:** The code should contains absolutely zero external dependencies, libraries, frameworks & crates. Only pure standard library or in-built API code is accepted.
