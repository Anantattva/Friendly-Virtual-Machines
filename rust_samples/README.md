## 🪻🪻 Rust VM Collection

This folder contains all sample virtual machines written in Rust.

## 🪙 Contents

As of November, 2026, it has about 7 samples:
- **Register-Based VMs:** 5 samples. Displaying how register-based vms work. Also displays hardware design & assembly.
- **Pure-Pointer VMs:** 1 sample. Displays how register-less or direct memory-to-memory vms work.
- **Stack-Based VMs:** 1 sample. Displays how stack-bases vms like CPython or JVM are designed.
